# プロジェクト名：　Python_to_Mindmap

## 特徴:  
Pythonコードについて、インデントをマインドマップのレベルとみなし、視覚的・インタラクティブに理解できるアプリです。  
貼り付けたPythonコードのインデント（段下げ）を解析し、クラスやメソッド、ステートメントなどを色分けします。  
インタラクティブに展開・折りたたみが可能なツリー図を作成します。  
マインドマップを作成後、HTMLファイルとして保存すれば検索機能が追加され、すべての検索結果が展開されて表示されます。  
マインドマップを作成後、.mmファイルとして保存すればマインドマップソフト（Freemind）で活用できます。  

## アプリのボタン類:  
「マインドマップを生成」  
「入力クリア」  
（ファイル名設定欄）  
「.mmとして保存（ダウンロード）」  
「HTMLとして保存（ダウンロード）」  
「すべて展開」  
「折りたたみ」  

## 生成されたHTMLファイルのボタン類  
「すべて展開」  
「折りたたみ」  
「検索」  
「クリア」  

## 使い方：  
HTMLファイルはダブルクリックしてブラウザ上で使用してください。  
.mmファイルはマインドマップソフト（Freemind）で開いてください。
